## Agent skills

### Issue tracker

Issues live as local Markdown under `.scratch/<feature>/`.
See `docs/agents/issue-tracker.md` before reading or publishing tickets.

### Triage labels

Use the five default triage roles.
See `docs/agents/triage-labels.md` when assigning triage status.

### Domain docs

Single-context: root `GLOSSARY.md` and `docs/adr/`.
See `docs/agents/domain.md` before exploring the codebase.

### Worklog

Read `worklog.md` before substantive changes and keep its current goal, status, decisions, blockers, and next action accurate when the tracked state changes materially.
