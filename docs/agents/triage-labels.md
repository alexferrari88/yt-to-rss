# Triage Labels

Use these strings for the local issue tracker's `Status:` field.

| Canonical role | Tracker string | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer must evaluate |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Fully specified; ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill names a triage role, use its tracker string.
